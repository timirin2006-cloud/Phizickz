# Физика начинается здесь — 7 класс

Интерактивный сайт для первого индивидуального урока физики по программе 7 класса.

## Как открыть
1. Скачайте `index.html`.
2. Откройте его в современном браузере (Chrome, Safari, Edge или Firefox).

## Как опубликовать через GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. После публикации GitHub покажет ссылку на сайт в разделе Pages.

Сайт не требует сервера или сторонних библиотек. Прогресс сохраняется локально в браузере ученицы. Для повторного прохождения используйте кнопку «Пройти урок ещё раз».
